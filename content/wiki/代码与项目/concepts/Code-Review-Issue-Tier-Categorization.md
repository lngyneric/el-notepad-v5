# Code Review Issue Tier Categorization

## Evolution Log
- 2026-04-24: 来自 [[code-reviewer]] 的认知：The standard prioritization framework used by the code-reviewer agent to classify identified issues into three priority tiers: Critical (must fix), Important (should fix), and Suggestions (nice to have), paired with specific, actionable remediation recommendations.
