# Superpowers for Codex 安装指南

## 摘要

Superpowers for Codex 的快速安装配置指南。核心步骤：克隆 superpowers 仓库到 `~/.codex/superpowers/`，创建 `~/.codex/skills/` 个人技能目录，在 AGENTS.md 中添加 Superpowers System 配置段落，运行 bootstrap 命令验证。

## 安装步骤

1. 克隆仓库到 `~/.codex/superpowers/`
2. 创建 `~/.codex/skills/` 目录
3. 更新 `~/.codex/AGENTS.md` 包含 Superpowers System 配置
4. 运行 `superpowers-codex bootstrap` 验证
