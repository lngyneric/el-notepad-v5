# Superpowers for OpenCode 安装指南

## 摘要

Superpowers for OpenCode 的安装配置指南。包含克隆仓库、创建 symlink 注册插件、使用 `find_skills`/`use_skill` 工具加载技能、个人技能与项目技能的创建方法、技能优先级（project > personal > superpowers）、工具映射说明以及故障排查。

## 技能优先级
- `project:skill-name` — 强制项目技能
- `skill-name` — 搜索 project → personal → superpowers
- `superpowers:skill-name` — 强制 Superpowers 技能
