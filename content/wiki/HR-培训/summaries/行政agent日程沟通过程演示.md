# project-reminder Skill 文档 - 行政前台日程管理

## 概述

本 Skill 基于 FastClaw AI Agent 框架，旨在帮助用户管理三个预设的项目类别（重要活动、自动化、每天的活），并为行政前台人员配置了完整的定时任务提醒系统。Skill 已保存至用户技能目录，可在下一轮对话中自动触发。

## 核心规则

Skill 定义了三个 Project 及其提醒规则：

| Project | 规则 | 提醒方式 |
| --- | --- | --- |
| **重要活动** | 必须设事件日期 | 前7天、前3天、前1天各提醒一次（`once`） |
| **自动化** | 周期性工作 | 每周一 09:00 说明上周 + 每周五 17:00 汇总本周（`cron`） |
| **每天的活** | 按时间排序 | 每天 09:00 准时提醒当日排好序的活动（`cron`） |

## 智能归类

用户只需说一句话，Skill 自动判断放入哪个 Project。例如：
- “下周五有个面试” → 重要活动（追问日期后设3个倒计时提醒）
- “每周同步一下进度” → 自动化（设周一9点+周五17点）
- “每天9点提醒我运动” → 每天的活（排序+每日9点提醒）
- 混合内容 → 分别处理三个 Project
