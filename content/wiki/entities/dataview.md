# Dataview

## 基本信息
- Type: product
- Source: [[raw/Wiki架构设计|Wiki架构设计]]

## 描述
Dataview 是 [[entities/Obsidian|Obsidian]] 生态系统中的一款核心插件，专为查询笔记页面前言（frontmatter）并生成动态表格和列表而设计。在 Wiki 架构中，Dataview 被列为特殊工具和插件之一，用于辅助维基维护，能够动态生成内容索引、统计页面元数据等，显著提升维基的可维护性和可视化能力。它允许用户通过类似 SQL 的查询语言（DQL）从笔记中提取结构化数据，是知识管理中的强大工具。Dataview 与 [[entities/Marp|Marp]]、[[entities/Obsidian Web Clipper|Obsidian Web Clipper]] 等工具共同构成了高效的维基维护工具链。通过 Dataview，用户可以轻松实现页面的自动化统计、标签聚合和内容概览。
